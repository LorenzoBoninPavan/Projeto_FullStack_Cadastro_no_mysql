# Projeto de Cadastro no MYSQL

#Sobre o Projeto

Este projeto web foi desenvolvido em PHP e MySQL com o objetivo de criar uma aplicação interativa para o gerenciamento de imagens. O sistema permite o upload de fotografias acompanhadas de informações de teste (como títulos ou descrições), o armazenamento seguro dos dados na base de dados e uma interface de listagem dinâmica equipada com um mecanismo de busca para filtrar os registos rapidamente.

#Funcionalidades e Fluxo da Aplicação

Upload e Cadastro de Imagens: Permite carregar ficheiros de imagem para o servidor e registar as respetivas informações textuais associadas diretamente na base de dados MySQL.

Listagem Dinâmica: Recupera e exibe de forma organizada todas as fotos cadastradas no sistema em formato de galeria.

Mecanismo de Busca: Um campo de pesquisa integrado que consulta o banco de dados em tempo real, permitindo ao usuário filtrar e encontrar fotos específicas por meio de termos cadastrados.

Persistência de Dados (MySQL): Utilização de estruturação relacional para salvar o caminho/nome do arquivo da imagem junto com os metadados informados.

#Tecnologias Utilizadas

Linguagem Backend: PHP (Processamento de formulários, manipulação de arquivos e conexão com o banco)

Banco de Dados: MySQL (Armazenamento estruturado de metadados e caminhos das imagens)

Frontend: HTML5 e CSS (Estruturação de formulários, grades/layouts de exibição e barra de pesquisa)
